# STONE_PAPER_SCISSOR_GAME
Stone Paper Scissor Game

An interactive Stone Paper Scissor game built using HTML, CSS, and JavaScript. This project allows users to play against the computer in a fun and engaging way while demonstrating core JavaScript concepts such as DOM manipulation, event handling, random number generation, game logic implementation, and score tracking.

Features

- Interactive gameplay against the computer
- Real-time score tracking
- Random computer move generation
- Dynamic result updates (Win, Lose, Draw)
- Responsive and user-friendly interface
- Clean and organized code structure

Technologies Used

- HTML5
- CSS3
- JavaScript 

Purpose

This project was developed to strengthen JavaScript fundamentals and gain hands-on experience in building interactive web applications.

Learning Outcomes

- DOM Manipulation
- Event Handling
- Conditional Statements
- Functions and Logic Building
- JavaScript Fundamentals
- Responsive Web Design

Feel free to fork, modify, and enhance the game with additional features such as animations, sound effects, difficulty levels, and multiplayer support.
